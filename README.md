# Mermaid Kaz - Professional Mermaid Services

Professional mermaid services: children's parties, PADI certification courses, and dive tours.

## What We're Building

A simple booking-focused website that lets Kaz update content and clients book services.

**Stack**: Eleventy + Decap CMS + Cloudflare Pages + TidyCal integration

## Essential Requirements

**Pages Needed:**
- Home (hero + services overview)
- Services (parties, certification, tours) 
- Book Now (TidyCal embed)
- About Kaz
- Blog (weekly posts max)

**Must Have:**
- Responsive design
- Accessible navigation (keyboard, screen readers)
- TidyCal booking integration
- Decap CMS for content updates
- Auto-deploy from GitHub to Cloudflare Pages
- Basic browser translation support

**Technical:**
- Eleventy static site generator
- Decap CMS at `/admin/` (GitHub OAuth)
- Cloudflare Pages hosting (free tier)
- Images in `/uploads/` folder

## Launch Checklist

- [ ] Basic site structure
- [ ] TidyCal booking embed
- [ ] CMS content collections
- [ ] GitHub Actions deploy
- [ ] Domain + SSL setup
- [ ] Accessibility audit
- [ ] Basic SEO meta tags

That's it. No staging environments, no performance monitoring, no GDPR compliance planning. Build what's needed to take bookings.
